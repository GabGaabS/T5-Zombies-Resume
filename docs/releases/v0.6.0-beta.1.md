# T5 Zombies Resume v0.6.0-beta.1

This beta adds the first **Resume Game button** to the private BO1 Zombies lobby.

The save runtime still uses format v6, so saves created with 0.5.0-beta.2 remain compatible.

## New: private-lobby Resume Game

Install the optional menu layer with Plutonium closed:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -InstallMenu
```

When the host has a valid v6 save, the private lobby should show:

```text
T5ZR - RESUME GAME
```

Selecting it chooses the saved stock Zombies map, arms the resume and starts the match. A normal Start Match clears the resume flag first.

Remove the UI layer at any time:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -RemoveMenu
```

If an existing custom private-lobby menu was present, T5ZR backs it up and restores it when removing the integration.

## Packaging

The T5ZR repository does not ship Plutonium's full lobby menu asset.

For `-InstallMenu`, the installer downloads a pinned public raw asset from `plutoniummod/client-raw-assets` and applies the small T5ZR patch locally.

## Save/runtime features

- round resume;
- points;
- weapons and ammo;
- selected weapon;
- perks;
- per-player GUID matching;
- coop scoreboard fields;
- hellhound scheduler continuity;
- Kino power and opened routes;
- Kino curtain / fully-linked teleporter state.

## Known limitations

Mystery Box history, active temporary timers/powerups, mid-round zombies, Easter Egg progress and unsupported map-specific world state are not reconstructed.

## Compatibility

Developed primarily against Plutonium T5 r5346. The optional menu layer is new in this beta and should be treated as experimental until tested on the current client build.
