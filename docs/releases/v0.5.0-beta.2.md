# T5 Zombies Resume v0.5.0-beta.2

Second public-beta candidate for T5 Zombies Resume.

This build follows the first full Kino der Toten resume test. Player loadouts, perks, power and opened routes survived a complete BO1/Plutonium restart. Beta.2 fixes the two remaining issues found in that test: the coop scoreboard and hellhound-round scheduling.

## What changed

- **Coop scoreboard restore**
  - restores kills;
  - headshots;
  - downs;
  - revives;
  - keeps BO1's networked player fields and internal Zombies stat mirrors synchronized.

- **Hellhound rounds**
  - saves whether stock dog rounds are enabled;
  - saves the current dog-round count;
  - saves `next_dog_round`;
  - saves whether the autosave boundary had already queued a dog round;
  - restores the stock dog spawn path when the resumed round itself is a hellhound round.

- Existing beta.1 functionality remains:
  - round;
  - points;
  - weapons and ammo;
  - selected weapon;
  - perks;
  - strict GUID matching;
  - Kino power;
  - permanent opened doors/debris;
  - stage curtain;
  - fully-linked teleporter.

## Save format

Beta.2 uses **save format v6**.

A v5 save from beta.1 is deliberately not resumed. After installing beta.2, finish at least one round to create a fresh v6 save.

## Install

Close Plutonium completely, then run:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Expected installer version:

```text
[T5ZR] T5 Zombies Resume 0.5.0-beta.2
[T5ZR] Runtime attendu : 0.5.0-beta.2 / save format v6
```

## Resume

Check the saved state:

```text
set zr_status 1
```

Resume:

```text
set zr_resume 1
map_restart
```

For hellhound debugging, status now also prints:

```text
dogs_enabled=...
dog_active=...
dog_count=...
next_dog_round=...
```

## What still is not reconstructed

- Mystery Box position/history;
- active teleporter cooldown;
- temporary traps or powerups;
- living zombies and exact mid-round positions;
- Easter Egg / sidequest progress;
- RNG state;
- full map-specific world state outside implemented adapters.

## Compatibility

Developed and tested primarily on **Plutonium T5 r5346**.

No external DLL is required. The old `t5-gsc-utils.dll` prototype dependency is not used.

## Bug reports

Please include the Plutonium build, map, player count, saved round, expected vs. actual result and relevant `[T5ZR]` console lines.

For dog-round issues, include the four dog scheduler values from `set zr_status 1`.

Redact GUIDs, IPs, account tokens and personal filesystem paths before posting logs.
