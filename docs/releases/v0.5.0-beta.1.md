# T5 Zombies Resume v0.5.0-beta.1

First public beta of T5 Zombies Resume.

T5ZR lets the host of a private **Call of Duty: Black Ops Zombies** session on **Plutonium T5** save at a round boundary, close the game, and reconstruct the session later.

## Highlights

- Host-only installation; other players do not need the script.
- No external DLL required.
- Save persists after a full BO1/Plutonium restart.
- Strict per-player matching with `GetGuid()`.
- Restores the next round, points, weapons, clip/reserve ammo and selected weapon.
- Restores active Zombies perks through Treyarch's stock perk logic.
- v5 adds kills, headshots, downs and revives to the reconstructed session state.
- First map-specific world adapter: **Kino der Toten**.

### Kino der Toten in v5

The beta attempts to restore:

- power;
- permanent opened doors/debris and their zombie-zone flags;
- stage curtain completion;
- a fully-linked teleporter.

This is the newest part of the beta and should be treated as test coverage, not a guarantee of perfect map reconstruction on every setup.

## Install

Close Plutonium completely, extract/clone the repository, then run:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

The installer copies the GSC to the Plutonium T5 Zombies script folder and registers the persistent save dvars in `players/config.cfg`.

## Save and resume

Autosave runs automatically when the game advances to the next round.

Check the save:

```text
set zr_status 1
```

Resume:

```text
set zr_resume 1
map_restart
```

Manual save:

```text
set zr_save_now 1
```

Clear the save:

```text
set zr_clear_save 1
```

## Upgrading from 0.4.x

`0.5.x` uses **save format v5**. Existing v4 data is not deleted, but the v5 runtime will not resume it.

After installing this beta, play through at least one round to create a fresh v5 save before testing resume.

## Known limitations

Not currently reconstructed:

- Mystery Box location/history;
- teleporter cooldown or an in-progress teleport;
- active traps and temporary powerups;
- living zombies / mid-round positions;
- Easter Egg and sidequest progress;
- RNG state;
- map-specific world state outside Kino.

Other BO1 Zombies maps can still use the player/round snapshot, but their world state resets normally.

## Compatibility

Developed and tested primarily against **Plutonium T5 r5346**. Future Plutonium builds may require changes.

`t5-gsc-utils.dll` is not required. On the r5346 development setup it caused an early `ddl/stats.ddl` initialization failure, so users upgrading from very old T5ZR prototypes should keep that DLL disabled.
